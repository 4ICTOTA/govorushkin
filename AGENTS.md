# Говорушкин Site — инструкции агенту

- Общайся и веди документацию на русском; идентификаторы в коде — английские.
- Начни с `git status`, README и `docs/STATE.md`. Сохраняй изменения владельца.
- Это отдельный публичный репозиторий информационной страницы. Код приложения,
  Supabase, токены, личные контакты и закрытые документы сюда не переносятся.
- Используй обычные HTML / CSS и локальные ресурсы. Не добавляй framework, сборку,
  JavaScript, аналитику, формы или пакеты без конкретной согласованной задачи.
- Название — «Говорушкин», герой и приветствие — «Герка Говорушкин».
  Оформление, Nunito и брендовые ресурсы соответствуют приложению. Сохраняй OFL.
  Различай существующий интерфейс и планируемые упражнения. Не заявляй
  готовность оплаты, выпуск в RuStore или медицинскую эффективность.
- Пиши кратко и по делу, убирай повторные пояснения и расплывчатые слоганы.
  Для перечислений используй запятые, не точки-разделители.
- Исправляй поведение в ответственном слое; сохраняй доступность и адаптивность.
- Перед завершением: `git diff --check`, реальный браузер без окна и звука,
  навигация, desktop / mobile, проверка переполнений и ошибок, осмотр кадров.
  Артефакты держи в игнорируемом `output`. Проверь diff и содержимое публикации.
- Публикуется только `public`. Обновления исходников проходят через Pages workflow.
  Новые рабочие ветки — `codex/<task>`. Коммить только проверенную работу.
- README владеет устройством и командами, STATE — результатами и ограничениями.
