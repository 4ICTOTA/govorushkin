# Состояние сайта

18.11.2026. Сайт знакомит с «Говорушкиным», Android-приложением для домашней
речевой практики детей 4–7 лет по рекомендациям логопеда.

- Сайт показывает четыре направления и шесть экранов Android-приложения.
  Галерея показывает старт без входа и раздел «Родителям» в обычной сборке.
  Проверка покупки проводится
  в отладочной сборке приложения.
- [GitHub Pages](https://4ictota.github.io/govorushkin/) публикует папку
  `public/`. Для обратной связи используются [GitHub Issues](https://github.com/4ICTOTA/govorushkin/issues).

## Проверки

- Обновлённая страница проверена в Chromium на ширинах 1440, 390 и 320 px
  в обеих темах. Галерея открывается из навигации, шесть снимков и Nunito
  загружаются. Проверены переход на лицензию и возврат на главную.
- Переполнений, ошибок страницы и неудачных загрузок нет. Кадры сохранены перед публикацией. `git diff --check` и ссылки документации проверены.
