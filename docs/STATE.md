# Состояние сайта

17.11.2026. Реализован редизайн «Говорушкин» по варианту «Знакомство с Геркой».
Герой и приветствие используют полное имя — Герка Говорушкин.

## Реализовано

- Общие с Android-приложением Nunito, палитра двух тем, иконка и иллюстрация
  героя. Текстовые начертания, скругления и названия направлений согласованы.
- Первый экран, четыре направления, три настоящих экрана приложения,
  информация для родителей, статус проекта и публичный контакт GitHub Issues.
  Главный экран снят на Honor после обновления приветствия в приложении.
- Обычные HTML/CSS и локальные ресурсы, без JavaScript и внешних запросов.
  Экраны загружаются лениво. Полная статика — **392 295 байт** без сжатия.
- Портретная/горизонтальная компоновка, системная тёмная тема, переносы текста,
  кликабельные элементы от 48 CSS px, skip link и видимый клавиатурный фокус.
- Отдельная страница лицензии Nunito; исходный OFL сохранён рядом со шрифтом.
  Устаревшие Speech Practice и SVG-иконка удалены из интерфейса.

## Последние проверки

- `git diff --check`, локальные ссылки/файлы/якоря и уникальные id — успешно.
  Файл Nunito побайтово совпадает с используемым в приложении.
- Chromium без окна и звука: **24 конфигурации** — 1440×900, 1024×768,
  768×1024, 844×390, 390×844 и 320×568; обе темы; текст 100% и 200%.
  Горизонтального переполнения нет, тексты внутри доступной ширины,
  карточки в строке равны, все изображения и шрифт загружаются.
- Реальные нажатия: CTA «Посмотреть экраны», навигация к родителям и описанию,
  возврат наверх, открытие лицензии. Tab/Enter переводят фокус со skip link
  на main. Ошибок страницы, предупреждений и неудачных загрузок нет.
- Осмотрены полные кадры desktop/mobile, тёмная версия и узкое окно с текстом
  200%. Кадры, сценарий и журналы — в игнорируемом output/site-redesign.
- WebKit не запускался: соответствующий браузер Playwright не установлен.
  Реальные мобильные Safari/Chrome этим этапом не проверялись.

Публичный репозиторий: https://github.com/4ICTOTA/speech-practice-site
GitHub Pages: https://4ictota.github.io/speech-practice-site/

Редизайн находится в локальной ветке codex/govorushkin-site и ещё не отправлен
в GitHub. Опубликованный сайт остаётся на предыдущей версии; автоматическая
публикация произойдёт после попадания public в main. Отдельный сервис не добавлен.
Приватное Android-приложение и бесплатные материалы остаются в своих репозиториях.

Это информационная страница, а не браузерный проигрыватель упражнений.
Упражнения ещё готовятся; сайт не обещает готовые учётки, прогресс, запись
голоса, выпуск в RuStore или оплату. Медицинская эффективность не заявлена.
Платёжная интеграция и обращение в Робокассу этим этапом не менялись.
