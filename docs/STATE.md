# Состояние сайта

23.11.2026. Сайт знакомит с «Говорушкиным», Android-приложением для домашней
речевой практики детей 4–7 лет по рекомендациям логопеда.

- Сайт показывает четыре направления с обложками из приложения и шесть
  снимков обычной сборки с эмулятора Android API 36. В галерее видны
  главная, «Родителям», выбор свистящих, Р, Рь и «Артикуляция».
  Проверка покупки проводится в отладочной сборке приложения.
- [GitHub Pages](https://4ictota.github.io/govorushkin/) публикует папку
  `public/`. Для обратной связи используются [GitHub Issues](https://github.com/4ICTOTA/govorushkin/issues).

## Проверки

- Страница проверена в Chromium в 24 сценариях на ширинах от 320 до 1440 px,
  в обеих темах, при масштабе текста 100% и 200%. Проверены навигация,
  управление с клавиатуры, переход на лицензию и возврат на главную.
- Все шесть снимков, иллюстрации и Nunito загружаются. Переполнений и ошибок
  браузера нет. Локальные ссылки и `git diff --check` проверены.
