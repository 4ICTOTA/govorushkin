# Состояние сайта

18.11.2026. Сайт знакомит с «Говорушкиным», Android-приложением для домашней
речевой практики детей 4–7 лет по рекомендациям логопеда.

- Приветствие и четыре карточки направлений используют новые ростовые
  иллюстрации Герки. Самолёт игрушечный, у направлений разные предметы.
- Герой в карточках увеличен: общий портретный viewport сохраняет фигуру
  целиком и убирает прозрачные боковые поля. Отступы текста отделены
  от изображения. Снимки входа, главной и выбора звука обновлены после
  корректировки масштаба и стрелок в приложении.
- Галерея показывает шесть реальных экранов: вход с тремя кнопками VK ID,
  занятия, выбор шипящих, звуки Р и Рь, артикуляцию. Вход снят на эмуляторе
  Android API 24, остальные кадры — на Honor 20. Пропорции кадров сохранены.
- Страница показывает текущий вход и сообщает о подготовке упражнений. Публичного доступа к
  аккаунтам, записи голоса, установки из RuStore и оплаты на сайте нет.
- Публичный репозиторий [govorushkin](https://github.com/4ICTOTA/govorushkin).
  Стабильный адрес [GitHub Pages](https://4ictota.github.io/govorushkin/).
  Обратная связь — публичные GitHub Issues.

## Проверки

- Chromium без окна и звука: 24 конфигурации. Размеры 1440×900, 1024×768,
  768×1024, 844×390, 390×844 и 320×568, обе темы, текст 100% и 200%.
- Галерея содержит шесть снимков, карточки — четыре отдельные иллюстрации.
  Снимки, иллюстрации и локальный Nunito загружаются.
  Проверены равные карточки, отсутствие горизонтальной прокрутки,
  переходы к разделам, клавиатурный фокус и страница лицензии. Ошибок
  браузера или неудачных загрузок нет. Центральных точек-разделителей нет.
  Кадры и журнал — `output/redesign-*`.
- `git diff --check` прошёл. В публикацию входит только `public/`.
