# Состояние сайта

18.11.2026. Сайт знакомит с «Говорушкиным», Android-приложением для домашней
речевой практики детей 4–7 лет по рекомендациям логопеда.

- Сайт показывает четыре направления и шесть экранов Android-приложения.
  Галерея состоит из кадров обычной сборки. Проверка покупки проводится
  в отладочной сборке приложения.
- [GitHub Pages](https://4ictota.github.io/govorushkin/) публикует папку
  `public/`. Для обратной связи используются [GitHub Issues](https://github.com/4ICTOTA/govorushkin/issues).

## Проверки

- Опубликованная страница проверена в Chromium на 1440×900, 390×844 и
  320×568. Галерея открывается из навигации, шесть снимков и Nunito
  загружаются. Проверены Tab, переход на лицензию и возврат на главную.
- Переполнений, ошибок страницы и неудачных загрузок нет. Кадры сохранены
  в `output/audit/`. `git diff --check` и ссылки документации проверены.
