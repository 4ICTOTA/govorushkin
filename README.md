# Говорушкин — публичная страница

Информационный сайт Android-приложения для домашней речевой практики детей
4–7 лет по рекомендации логопеда. Герой — Герка Говорушкин.
Приложение в разработке; упражнения готовятся, платежи на сайте не принимаются.

Публичный репозиторий: https://github.com/4ICTOTA/govorushkin

Адрес GitHub Pages: https://4ictota.github.io/govorushkin/
Локальная папка — `govorushkin-site`. Приложение и бесплатные материалы
находятся в отдельных репозиториях `govorushkin-app` и `govorushkin-content`.
[Состояние исходников, проверки и публикация](docs/STATE.md).

## Устройство

`public` — готовый статический сайт: HTML, CSS, локальный Nunito, иконка,
пять WebP-иллюстраций и шесть экранов Android-приложения. Сборки, JavaScript,
сетевых шрифтов, аналитики, cookies, форм и зависимостей нет. Приватный код
приложения, backend и секреты в этот публичный репозиторий не входят.

Главная знакомит с проектом, показывает четыре направления, экраны,
информацию для родителей и публичный контакт через GitHub Issues.
Навигация работает обычными ссылками. `licenses.html` содержит полный текст
лицензии Nunito; оригинальный OFL.txt сохраняется рядом со шрифтом.
Только `public` передаётся в GitHub Pages; документация и `output` не публикуются.

## Оформление и ресурсы

Визуальный эталон — приложение «Говорушкин»: тот же файл Nunito с кириллицей,
начертания 400–900, иконка и Герка Говорушкин. Приветствие использует полное имя.
CSS-переменные владеют палитрой: молочный #FAF8F2, текст #263E43,
основной зелёный #2F726A, поверхности направлений #E2F0EA / #E8F1F8 /
#EEEAF6 / #F7ECD6. Тёмные цвета соответствуют системной теме приложения.
Карточки имеют скругление 24 px, блок героя — 26 px, кнопки — 18 px.

Сетка перестраивается по доступной ширине; размер текста задаётся в rem.
На узких окнах и при увеличении текста разделы переходят в одну колонку.
Нет фиксированной высоты текста, запрета масштабирования или автопрокрутки.
Кликабельные элементы имеют высоту не меньше 48 CSS px. Картинки задают
пропорции заранее; экраны ниже первого блока загружаются лениво.

В приветствии используется Герка в полный рост, в карточках направлений —
отдельные сцены с паровозиком, листом, игрушечным самолётом и зеркалом.
Иллюстрации соответствуют приложению; размер сцен в карточках — 104×152 CSS px.
Портретная область убирает только прозрачные боковые поля квадратного ресурса,
сохраняя героя целиком и без искажения пропорций. Вертикальные отступы
принадлежат тексту, поэтому изображение занимает почти всю высоту карточки.
Галерея показывает вход, занятия, выбор шипящих, звуки Р и Рь, артикуляцию.
Снимки работающего приложения сделаны на Honor 20, вход — на эмуляторе
Android API 24. Пропорции кадров разных устройств сохраняются. В галерее
видны синие твёрдые и зелёные мягкие звуки, отдельная сцена Рь с репкой.
Упражнения ещё готовятся; раздел артикуляции открывается без покупки.
Изображения уменьшены и сохранены в WebP для сайта, исходники и макеты
генерации остаются локально вне Git.

[Nunito / Google Fonts](https://github.com/google/fonts/tree/main/ofl/nunito)
распространяется по SIL OFL 1.1: `public/assets/fonts/OFL.txt`.
SVG-значки интерфейса нарисованы непосредственно в HTML.

## Локальный просмотр и проверка

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory public
```

Откройте http://127.0.0.1:4173/. Установка пакетов не требуется.
Перед публикацией: `git diff --check`, проверка локальных ресурсов и якорей,
реальные переходы по ссылкам и Tab / Enter в браузере без окна и звука.
Проверьте обе темы, портретные/горизонтальные окна, ширины от 320 px и текст
200%: отсутствие переполнений, одинаковые карточки в строке, загрузку Nunito,
иконки и всех изображений, доступность последнего блока. Кадры и журналы —
в игнорируемом `output`. Проверки браузера не входят в публикацию.

При замене оформления проверьте ссылки из обоих HTML-файлов и CSS,
удалите оставшиеся без использования ресурсы и селекторы. `OFL.txt`
сохраняется вместе со шрифтом, даже без прямой ссылки из HTML.

Основания: [локальный шрифт @font-face](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@font-face),
[адаптивный интерфейс](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design).

## Публикация

Push изменений `public/**` или workflow в `main` запускает GitHub Pages через
GitHub Actions; также есть ручной запуск. Actions закреплены полными SHA.
Docs-only изменения не вызывают публикацию. Перед отправкой сверяйте diff:
в публичную поставку входят только одобренные брендовые ресурсы и тексты.

Страница представляет разрабатываемый проект. Готовые упражнения, установка
из RuStore, браузерное прохождение и приём оплаты не заявлены.
При переходе к продажам нужно заново проверить требования
[GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)
и [Робокассы](https://robokassa.com/payments/internet-ekvayring/).
