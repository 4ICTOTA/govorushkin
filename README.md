# Speech Practice — публичная страница

Информационная страница Android-проекта речевых упражнений.
Приложение находится в разработке, платежи на странице не принимаются.

Публикация: https://4ictota.github.io/speech-practice-site/

## Устройство

В `public` находятся HTML, CSS и собственная SVG-иконка. JavaScript, внешние
шрифты, аналитика, cookies, формы и зависимости отсутствуют. Файлы приложения,
backend и секреты в этот публичный репозиторий не входят.

Только содержимое `public` передаётся в GitHub Pages. Документация и локальные
артефакты проверки в опубликованный сайт не включаются.

## Локальный просмотр

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory public
```

Откройте http://127.0.0.1:4173/. Сборка и установка пакетов не нужны.
Перед публикацией: `git diff --check`, просмотр desktop / mobile в браузере,
проверка навигации, ссылок, загрузки CSS / иконки и отсутствия ошибок.

## Публикация

GitHub Pages использует GitHub Actions. Push изменений `public/**` или workflow
в `main` запускает публикацию; также доступен ручной запуск workflow Pages.
Actions закреплены полными SHA. Собственный домен и сторонний хостинг не нужны.

Границы содержания: описание разрабатываемого проекта, планы, статус и публичная
обратная связь. Страница не является платёжной формой или торговой витриной.
При переходе к продажам нужно заново проверить требования
[GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)
и [Робокассы](https://robokassa.com/payments/internet-ekvayring/).
